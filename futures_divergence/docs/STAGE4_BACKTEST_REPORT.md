```bash
cd futures_divergence

python -m perpdiv backtest --override exp.yaml   # 설정 바꿔 비교 (예: 익절 방식)
```

## 4. 리스크·가정 (★ = 5단계 전에 결정 필요)

1. **★ 킬 스위치가 백테스트에서 영구 정지** — 요구사항대로 수동 해제만 허용하므로, 규칙 적용 버전은 2024-02-29 이후 거래가 없다(성과 비교가
   사실상 "두 달 운용"). 5단계 평가를 (a) 규칙 미적용으로 전략 자체의 성과를 보고 규칙은 실거래에서만 적용할지, (b) 킬 스위치 발동 후
   일정 기간(예: 7일) 뒤 해제되는 모의 규칙을 추가할지 결정이 필요하다.
2. **★ 100% 진입 + ATR 손절 = 거래당 위험이 들쭉날쭉** — 손절폭이 곧 평가금액 손실률이라 15분봉도 90% 분위 9%, 최대 62% 이고, MDD 96% 가
   나왔다. 요구사항(평가금액 100%)을 그대로 따른 결과다. 위험 기준 사이징(예: 거래당 평가금액의 2% 손실, 명목가 상한 100%)이나 손절폭 상한을
   넣을지 결정이 필요하다. 넣지 않으면 5단계 몬테카를로의 "MDD 30% 도달 확률"은 매우 높게 나올 것이다.
3. **비용 민감도** — 비용 전 +926% 가 슬리피지×1 에서 +220%, ×2 에서 +103%. 기대값(R)은 비용 후 0 근처(−0.018)로, 성과의 상당 부분이
   2024년의 소수 큰 수익과 복리에서 나온다. 15분봉은 비용 후 기대값이 음수(−0.067R)다.
4. **국면 의존** — 2024 진입 +0.085R, 2025 −0.093R, 2026 −0.102R. 한 해의 결과로 전략을 판단하기 어렵다 → 5단계 walk-forward 로 확인.
5. **정밀 모드 영향 없음** — 손절 2.5 ATR, 익절 2R 이 한 15분봉 안에서 동시에 닿은 거래가 없었다(1분봉을 받을 일도 없었음).
6. **가정** (DESIGN §7.1): 수량 단위는 kline 거래량 소수 자릿수로 추정(실거래는 exchangeInfo), 최소 명목가 5 USDT(BTC 100, ETH 20),
   평가금액·리스크 판정은 15분봉 마감 기준, 킬 스위치 keep_stops 는 기존 손절·익절·시간 청산 유지, 신호 시각 시가에 갭 손절이 나면 그 시각의
   새 신호는 보유 중 스킵, 봉 내부 청산 시각은 그 15분봉 시작으로 기록, 청산가는 레버리지 > 1 에서만.
7. **유니버스** — 상장폐지 코인 포함(후보 560개 중 98개 폐지). 이 설정에서는 보유 중 폐지로 청산된 거래는 없었다. 순위 1~10 진입 분포는
   고르게 60~78건. TradFi 181개 제외(2026 년 NVDA·MU 등 상위권 코인이 빠짐).
8. **3단계 항목 B** (같은 t1 이 p2 교체 후 다시 신호) 는 답이 없어 요구사항 문구대로((t1, p2) 조합당 1회) 두었다.

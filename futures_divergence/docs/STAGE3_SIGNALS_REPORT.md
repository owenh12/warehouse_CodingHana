규칙 요약 (강세, 약세 대칭): t1 = 확정 피벗 저점, RSI(t1) < 30 → p2 = t1 이후 확정된 최고 피벗 고점(더 높은 피벗 고점이
확정되면 교체) → t3 = `Close < min(Low[p2..t3−1])` 인 봉, `High(p2) ≥ max(High[t1..t3−1])`, `Close(t3) < Low(t1)`,
`RSI(t3) > 30`, t3−t1 ≤ 60봉, (t1, p2) 조합당 1회, 한 봉에 여러 구조가 성립하면 신호 1건(가장 최근 t1).

### 3.3 검증

- **정의 대조**: 요구사항 문장을 그대로 옮긴 O(n²) 단순 구현과 증분 구현의 신호가 무작위 데이터 3종 × 설정 8종에서 완전히 일치
  (L/R 1~3, 동률 규칙 2종, 간격 상·하한, oversold 변경, 극값 옵션).
- **약세 = 강세 반전**: 가격을 뒤집은 데이터의 약세 신호가 원래 데이터의 강세 신호와 인덱스·이탈 기준까지 일치.
- **경계 테스트**: Close(t3) = Low(t1), Close = 이탈 기준, RSI = 30 은 모두 불성립(엄격 부등호). 이탈 봉 실패 후 다음 봉 재판정,
  조합당 1회, 더 높은 피벗 고점에 의한 p2 교체, 피벗 아닌 더 높은 봉에 의한 무효, t1 봉 자신의 고가 포함, 동률 규칙에 따른 p2 차이,
  간격 상·하한, 한 봉 동시 성립 → 1건(최근 t1), 워밍업 중 RSI → 구조 없음.
- **미래참조**: 앞부분만 넣은 결과 = 전체 결과의 앞부분 (4개 지점), 이후 봉을 바꿔도 이전 신호 불변, 신호 레코드의 모든 값이
  t3 마감 시점까지의 데이터와 일치, p2 확정 봉 ≤ t3.
- **육안 확인** (갤러리): 4h 20건 전부, 1d 1건, 1h·15m 표본을 확인했다. 표시된 t1·p2·t3 위치, Low(t1)선, 이탈 기준선, RSI 값이
  규칙과 일치했다. 예) 4h #2 롱: t1 111,866.3(RSI 23.7) → p2 → t3 종가 111,708.5 < 이탈 기준 112,155.6, RSI 36.2.
- 테스트 합계: 135 통과(신호 42 포함), 네트워크 옵트인 1 건너뜀. ruff·mypy strict 통과.

## 4. 리스크·가정 (★ = 확인 필요)

**A. ★ t1(p1)이 [t1, p2] 구간의 극값이 아닌 신호가 절반가량** — 요구사항에는 "t1 = 확정 피벗 저점"만 있고, t1 과 p2 사이에 더
낮은 저가가 나와도 구조를 버리라는 규칙이 없다. 그대로 구현하면 15m 220건 중 108건, 1h 74건 중 40건, 4h 20건 중 11건이 이런 경우다
(예: 4h #2 롱 — t1 뒤에 더 낮은 피벗 저점이 있지만 그 저점의 RSI 가 30 이상이라 자기 구조가 없고, 옛 t1 기준으로 신호).
일반적인 다이버전스 그림(첫 저점 → 반등 → 더 낮은 두 번째 저점)과는 다르다. 선택지:
- 그대로 (현재 기본, `anchor_must_be_extreme: false`)
- **t1 = min Low[t1..p2]** 요구 (`true`): 신호 15m 114, 1h 34, 4h 9, 1d 1. (더 낮은 저점에 RSI < 30 이면 그 저점이 자기 구조로 이어짐)
- 제안: `true`. 갤러리에서 "극값 아님" 필터로 해당 신호들을 볼 수 있다.

**B. ★ 같은 t1 이 p2 가 바뀐 뒤 다시 신호** — (t1, p2) 조합당 1회 규칙이라, 신호 후 더 높은 피벗 고점이 생기면 같은 t1 으로 새 조합이
신호를 낸다 (15m 15건, 1h 11건, 4h 3건. 예: 15m #2·#3 은 같은 p1 11:45, t2 가 13:30 → 16:00 으로 바뀜). 요구사항 문구 그대로이며
4단계에서는 보유 중이면 "보유 중 스킵"으로 집계된다. t1 당 1회로 바꿀지 확인이 필요하다.

**C. 형제 구조의 연속 신호** — 모든 t1 후보를 독립 추적하므로(1단계 결정) p2 가 같은 두 구조가 가격 조건 차이로 연속 봉에서 각각 신호를
낼 수 있다(15m #5·#6). 규칙대로이며 4단계에서 보유 중 스킵으로 처리된다.

**D. 근소한 가격 조건** — Close(t3) 가 Low(t1) 을 0.05% 미만으로 넘은 신호: 15m 57건(26%), 1h 6, 4h 2. 요구사항대로 인정한다.
최소 이탈 폭 필터는 5단계(파라미터 검증)의 후보로 남긴다.

**E. 차트의 진입·손절·익절 선은 참고용** — 다음 봉 시가 진입, 손절 Low(t3) − 2.5×ATR(t3), 익절 2R 을 그렸다. 체결·비용·동시 신호
우선순위·순위 필터(상위 10)는 4단계에서 적용한다. 3단계 신호는 순위 필터 없이 BTC 한 종목만 본 것이다.

**F. 이탈 기준이 Low(t1) 아래일 수 있음** — p2 와 t3 사이 봉이 꼬리로 t1 아래를 찍으면 이탈 기준이 그만큼 낮아진다(종가로 다시 깨야 함).
요구사항 정의 그대로다.
